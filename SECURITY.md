# Security Policy


LiveFolio takes the security of our software products and services seriously, which includes all source code repositories managed through our GitHub organizations.

If you believe you have found a security vulnerability, please report it to us as described below.

## Reporting Security Issues

**Please do not report security vulnerabilities through public GitHub issues.**

**Preferred channel — GitHub Private Vulnerability Reporting**

Use GitHub's built-in private advisory flow:

[Report a vulnerability →](https://github.com/LiveFolio-Cloud/LiveFolio-oss/security/advisories/new)
