# Premium SaaS Design System

> Category: Enterprise
> A high-fidelity, professional dark/light mode balanced system. Emerald accents on deep zinc. Best for dashboards, reports, and tech landing pages.

## Visual Theme & Atmosphere
Modern, efficient, trust-worthy. Subtle gradients, sharp borders, and high contrast. "The Apple of Enterprise Software."

## Color Palette & Tokens
- **Background (Light)**: `#FFFFFF` (Pure White)
- **Background (Dark)**: `#09090B` (Deep Zinc)
- **Primary Text**: `#09090B` (Light) / `#FAFAFA` (Dark)
- **Accent**: `#10B981` (Emerald Green)
- **Border**: `#E4E4E7` (Light Zinc) / `#27272A` (Dark Zinc)

## Typography
- **Font**: Sans-serif only (e.g., Inter, Geist, San Francisco).
- **Weights**: Bold for headers, Medium for UI labels, Regular for body.

## Component Rules
- **Buttons**: `rounded-md`. Primary is solid background.
- **Cards**: `rounded-lg` with subtle `1px` border. No outer shadows unless hovered.
- **Grids**: Use rigid 12-column layouts.

## Agent Prompt Guide
- Use consistent padding (e.g., `p-6` for cards, `p-12` for sections).
- Prefer emerald-500 for success and primary actions.
- Avoid Serif fonts entirely.
