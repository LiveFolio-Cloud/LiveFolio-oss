# Glassmorphic Quartz Design System

> Category: Creative
> A translucent, ethereal aesthetic. High-blur backgrounds, vibrant neon accents, and soft rounded geometry. Best for creative portfolios, app landing pages, and "Web3" looks.

## Visual Theme & Atmosphere
Lightweight, futuristic, multi-layered. Uses backdrop filters to create depth. "Interface like frosted glass."

## Color Palette & Tokens
- **Background**: Gradient from `#EEF2FF` to `#E0E7FF`.
- **Primary Text**: `#1E1B4B` (Deep Indigo)
- **Accent**: `#818CF8` (Vibrant Indigo)
- **Glass Card**: `rgba(255, 255, 255, 0.4)` with `backdrop-filter: blur(16px)`.

## Typography
- **Font**: Geometric sans-serif (e.g., Montserrat, Poppins, Lexend).
- **Style**: Wider tracking, uppercase for UI labels.

## Component Rules
- **Buttons**: `rounded-full` with soft glow shadows.
- **Cards**: `rounded-2xl` with glass effect.
- **Borders**: White `rgba(255, 255, 255, 0.2)` semi-transparent borders.

## Agent Prompt Guide
- Layering is essential. Use `z-index` and `shadow-xl` to imply hierarchy.
- Use vibrant gradients for primary buttons and accents.
- Soften all edges with large border-radius values.
