# Minimal Zinc Design System

> Category: Core
> The default LiveFolio aesthetic. Clean, neutral, and high-fidelity. Based on shadcn/ui principles.

## Visual Theme & Atmosphere
Neutral, objective, and professional. Focuses on content hierarchy and geometric precision. Uses a strict Zinc/Slate palette.

## Color Palette & Tokens
- **Background**: `#FAFAFA` (Zinc-50)
- **Primary Text**: `#09090B` (Zinc-950)
- **Secondary Text**: `#71717A` (Zinc-500)
- **Accent**: `#18181B` (Zinc-900)
- **Border**: `#E4E4E7` (Zinc-200)

## Typography
- **Font**: Clean Sans-serif (Inter, Geist, System UI).
- **Weights**: Semibold for titles, Medium for labels, Regular for body.

## Component Rules
- **Buttons**: `rounded-md` with sharp focus rings.
- **Cards**: `rounded-md` with subtle shadow and `1px` border.
- **Radius**: Standard `6px` (`rounded-md`) for all interactive elements.

## Agent Prompt Guide
- Do not use vibrant colors unless explicitly requested.
- Maintain strict alignment to the Zinc palette.
- Prioritize legibility and whitespace over decorative elements.
